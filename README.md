# 📋 TaskNotes Ultimate

تطبيق متكامل لإدارة المهام والملاحظات والعادات مع مؤقت بومودورو - مصمم بتصميم Glass عصري وأنيق.

![License](https://img.shields.io/badge/license-MIT-green.svg)
![Platform](https://img.shields.io/badge/platform-Web%20%7C%20PWA-orange.svg)

## ✨ المميزات الرئيسية

### 📝 إدارة المهام
- إنشاء وتعديل وحذف المهام
- تصنيف المهام حسب الأولوية (عالية، متوسطة، منخفضة)
- تحديد تاريخ الاستحقاق والتذكير
- إضافة مهام فرعية (Subtasks)
- دعم المهام المتكررة
- مؤشر تقدم للمهام

### 📁 المجلدات
- تنظيم المهام والملاحظات في مجلدات
- تخصيص لون وأيقونة لكل مجلد
- عرض تقدم المهام لكل مجلد
- تصميم بطاقات زجاجي (Glass Design) عصري

### 📝 الملاحظات
- إنشاء ملاحظات نصية غنية
- دعم القوائم (Checklists)
- تثبيت الملاحظات المهمة
- تصنيف الملاحظات بالألوان
- ربط الملاحظات بالمجلدات

### 🎯 تتبع العادات
- إنشاء عادات يومية وأسبوعية
- تتبع الإنجاز اليومي
- عرض سلسلة الإنجاز (Streak)
- تقويم أسبوعي للعادات
- إحصائيات مفصلة

### 🍅 مؤقت بومودورو
- مؤقت عمل قابل للتخصيص (25 دقيقة افتراضياً)
- استراحة قصيرة (5 دقائق)
- استراحة طويلة (15 دقيقة)
- تتبع عدد الجلسات
- إحصائيات التركيز

### 🗑️ سلة المهملات
- استعادة العناصر المحذوفة
- الحذف النهائي
- إفراغ السلة

### ⚙️ الإعدادات
- الوضع الفاتح والداكن
- دعم اللغتين العربية والإنجليزية
- استيراد وتصدير البيانات
- نسخ احتياطي

## 🎨 التصميم

- **تصميم Glass Modern**: تأثير الزجاج الضبابي الأنيق
- **تدرجات لونية جذابة**: ألوان متناسقة وعصرية
- **رسوم متحركة سلسة**: تأثيرات انتقالية راقية
- **تصميم متجاوب**: يعمل على جميع الأجهزة
- **دعم RTL**: واجهة عربية كاملة

## 📱 التطبيق التقدمي (PWA)

- يعمل بدون اتصال بالإنترنت
- قابل للتثبيت على الهاتف
- إشعارات محلية
- مزامنة في الخلفية

## 🛠️ التقنيات المستخدمة

- **HTML5**: هيكل التطبيق
- **CSS3**: التصميم والرسوم المتحركة
  - CSS Variables للتصميم المتناسق
  - Flexbox و Grid للتخطيط
  - Backdrop Filter لتأثير الزجاج
- **JavaScript**: المنطق والتفاعل
  - IndexedDB للتخزين المحلي
  - Service Worker للعمل Offline
  - Web APIs للإشعارات

## 📂 هيكل المشروع

```
task-app/
```

1. قم بتحميل الملف `index.html`
2. افتحه في المتصفح
3. ابدأ باستخدام التطبيق!
